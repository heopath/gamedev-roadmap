# 스프라이트와 루프

**컴퓨터공학 전공자가 게임에 직접 넣을 그림과 음악을 만들 수 있게 되는 12개월 계획**

목표는 *프로 수준*이 아니라 **게임에 넣어도 부끄럽지 않은 수준**입니다. 하루 30분, 순서대로 하나씩.


---

## 세 가지 원칙

| 원칙 | 내용 |
| --- | --- |
| **한 번에 하나만** | 그림과 음악을 동시에 시작하면 둘 다 안 늡니다. 그림이 먼저, 음악은 5개월차부터. |
| **날짜 수로 는다** | 주말에 몰아서 5시간보다 매일 30분이 낫습니다. 실력은 총 시간이 아니라 반복 횟수를 따라갑니다. |
| **미완성은 실력이 안 된다** | 30분이 지나면 상태가 어떻든 저장하고 올립니다. 완성 개수가 그대로 실력입니다. |

## 00 · 세팅 — 1주

여기서 시간을 쓰면 안 됩니다. 도구 고르느라 한 달 보내는 게 가장 흔한 실패입니다.

- [ ] 픽셀아트 툴 설치 — **Aseprite**(약 $20, 사실상 표준) 또는 **Pixelorama**(무료) *· 태블릿 필요 없음, 마우스로 합니다*
- [ ] Lospec에서 **16색 팔레트 3개** 내려받기 — 예: Endesga 32, Sweetie 16, PICO-8
- [ ] 결과물 저장소 만들기 — 깃 레포 하나에 **날짜 폴더**로 계속 쌓기
- [ ] 캘린더에 **매일 30분 블록** 반복 일정으로 등록 *· 시간을 정해두지 않으면 안 합니다*
- [ ] 완성 규칙 한 줄 써서 책상에 붙이기 — **"30분 지나면 무조건 저장하고 올린다"**

> **완료 기준** — 툴이 열리고, 캘린더에 반복 일정이 있고, 빈 저장소가 있다.

## 01 · 픽셀아트 기초 — 1~3개월 (주 5회 × 30분)

픽셀아트는 "그림을 잘 그리는" 기술이 아니라 **해상도를 낮춰 난이도를 낮추는** 기법입니다. 32×32 캔버스에서는 손기술보다 판단(형태가 읽히는가, 색을 몇 개 쓸 것인가)이 전부라서, 그림을 못 그려도 몇 주면 쓸 만한 게 나옵니다. **순서를 지키는 것이 중요합니다 — 색부터 손대면 안 늡니다.**

### 1-1 · 실루엣 (2주)

검은 덩어리만으로 뭔지 알아보이게 만드는 단계입니다. 여기서 읽히면 색을 아무리 못 칠해도 살아납니다.

- [ ] 32×32 캔버스에 **단색 실루엣 20개** — 검, 물약, 나무, 문, 열쇠, 방패, 버섯…
- [ ] 그중 5개를 남에게 보여주고 **뭔지 맞히는지 확인** *· 3개 이상 맞으면 통과, 아니면 5개 더*
- [ ] 잘 안 읽힌 것 3개를 **외곽선만 고쳐서** 다시 그리기

### 1-2 · 명암 (3주)

그림이 안 예뻐 보이는 이유의 대부분은 색이 아니라 명암입니다. 색은 아직 쓰지 않습니다.

- [ ] **흑백 3단계**(어두움·중간·밝음)로만 아이템 20개
- [ ] 광원 방향을 **왼쪽 위로 고정**하고 20개 내내 지키기
- [ ] 매번 **눈을 가늘게 뜨고** 형태가 남는지 확인 *· 뭉개지면 명암 대비가 부족한 것*
- [ ] 3단계로 부족했던 것 5개를 **4단계**로 다시 그려서 비교

### 1-3 · 색 (3주)

팔레트를 직접 만들지 마세요. 검증된 팔레트를 쓰고, 선택지를 줄이는 것으로 실력을 대신합니다.

- [ ] 받아둔 **16색 팔레트 안에서만** 아이템 20개
- [ ] 같은 스프라이트 하나를 **팔레트 3개로 각각** 칠해보기 *· 분위기가 어떻게 바뀌는지 체감*
- [ ] 쓰는 색을 **5개 이하로 제한**한 32×32 캐릭터 1개
- [ ] 같은 캐릭터의 **낮 / 밤 버전** — 팔레트만 바꿔서

### 1-4 · 애니메이션 (4주)

여기까지 오면 게임 하나를 만들 수 있습니다. 프레임 수를 늘리지 말고, 적은 프레임으로 읽히게 하세요.

- [ ] **4프레임 코인 회전** *· 애니메이션 입문의 정석*
- [ ] **6프레임 걷기 사이클**
- [ ] **8프레임 공격 모션** — 예비동작 3 + 타격 1 + 잔상 4 *· 예비동작이 타격감을 만듭니다*
- [ ] **모작 30개** 채우기 — 좋아하는 게임 스프라이트를 옆에 띄우고 그대로 따라 찍기

> **완료 기준** — 게임에 바로 넣을 수 있는 캐릭터 1종 + 대기·걷기·공격 애니메이션.

## 02 · 첫 출하 — 4개월차 (게임잼)

이 단계가 로드맵 전체에서 가장 중요합니다. "48시간 안에 어떻게든 끝내야 하는" 압박이 완벽주의를 없애주고, 무엇보다 **실제로 게임에 들어간 결과물**이 남습니다. 음악은 아직 무료 에셋을 써도 됩니다 — 이번엔 그림만 직접.

- [ ] **Ludum Dare** 또는 **GMTK Game Jam** 다음 일정 확인하고 캘린더에 등록
- [ ] 본 대회 전에 **혼자 48시간 미니잼** 1회 연습 *· 주제는 아무거나*
- [ ] 잼 참가 — **아트는 100% 직접**, 음악은 무료 에셋 허용
- [ ] **itch.io** 페이지 만들고 스크린샷 3장 + GIF 1개 올리기
- [ ] 회고 5줄 쓰기 — 뭐가 오래 걸렸나 / 뭐가 부족했나 / 다음엔 뭘 미리 만들어둘까
- [ ] 부족했던 것 하나를 **다음 2주 연습 과제**로 정해서 실행

> **완료 기준** — 남이 눌러서 플레이할 수 있는 링크 하나.

---

## 03 · 작곡 기초 — 5~8개월 (주 5회 × 30분)

여기서 전공이 유리해집니다. **음악 이론은 사실상 정수 연산입니다** — 음정은 반음 개수, 스케일은 12칸 배열의 패턴, 코드 진행은 상태 전이입니다. 이걸 규칙으로 이해하면 "감"으로 배우는 것보다 훨씬 빠릅니다.

### 3-1 · 세팅 (1주)

- [ ] DAW(작곡 프로그램) 설치 — **REAPER**(평가판 제한이 사실상 없음, 개인 라이선스 $60) 또는 **LMMS**(무료)
- [ ] 무료 음원 설치 — **Spitfire LABS**(실제 악기), **Vital**(신디사이저), **Surge XT**
- [ ] (선택) **25건반 MIDI 키보드** 2~3만원대 *· 없어도 마우스로 찍을 수 있습니다*
- [ ] 아무 소리나 넣어서 **파일로 내보내기(export)까지** 한 번 성공 *· 여기서 막히는 사람이 많습니다*

### 3-2 · 리듬 (3주)

멜로디부터 시작하면 십중팔구 막힙니다. 드럼이 곡의 뼈대입니다.

- [ ] 킥·스네어·하이햇만으로 **8마디 드럼 루프 10개**
- [ ] 좋아하는 게임 BGM **3곡의 드럼만** 귀로 따서 재현
- [ ] 같은 드럼 패턴을 **템포 3가지**로 들어보고 분위기 차이 기록

### 3-3 · 코드 (4주)

한 조성에서 쓰는 7개 코드(다이어토닉 코드)만 알면 게임 음악의 대부분이 설명됩니다. 이론서보다 실제 곡의 코드를 보는 게 빠릅니다.

- [ ] **다이어토닉 7코드** 외우기 — C조 기준 `C · Dm · Em · F · G · Am · Bdim`
- [ ] **Hooktheory**에서 게임 BGM 10곡의 코드 진행 확인하고 공통 패턴 적기
- [ ] **4코드 루프 20개** 만들기 *· 멜로디 없이 코드만*
- [ ] 같은 진행을 **메이저 / 마이너**로 바꿔서 각각 저장 *· 마을 ↔ 던전 분위기*

### 3-4 · 멜로디와 루프 (6주)

루프 이음새와 레이어링은 일반 작곡 강의에 잘 안 나오는데, 게임 음악에서는 이게 핵심입니다.

- [ ] 만들어둔 코드 루프 위에 **멜로디 얹기 10개**
- [ ] **30초 BGM 완성 5곡** *· 완성 = 내보내기까지*
- [ ] **루프 이음새** 다듬기 — 끝에서 처음으로 돌아갈 때 티가 안 나게
- [ ] **레이어링** 실험 — 같은 곡의 "평상시 / 전투" 두 버전을 드럼·리드 트랙 on/off 만으로
- [ ] 게임 BGM **3곡 모작** — 귀로 듣고 MIDI로 그대로 재현

> **완료 기준** — 게임에 넣어도 되는 30초~1분 루프 BGM 3곡, 그리고 레이어 분기 버전 1곡.

## 04 · 통합, 그리고 전공 살리기 — 9~12개월

여기서부터는 손기술이 아니라 코드로 격차를 메웁니다. 단순한 스프라이트 하나도 셰이더로 아웃라인·피격 플래시를 넣으면 화면이 훨씬 좋아 보입니다. 그림을 더 잘 그리는 것보다 **이쪽이 투자 대비 효과가 큽니다.**

### 4-1 · 전공으로 메우기

- [ ] **셰이더 1개** 직접 붙이기 — 피격 플래시 또는 아웃라인
- [ ] **오디오 매니저** 작성 — 상황에 따라 트랙을 켜고 끄며 곡을 분기
- [ ] **팔레트 스왑 스크립트** — 색만 바꿔 적 캐릭터 변형 자동 생성
- [ ] 스프라이트 **아틀라스 자동 패킹** 파이프라인 만들기

### 4-2 · 전부 직접 만든 게임 하나

- [ ] 아트 + 음악 **전부 직접** 만든 게임 1개 *· 플레이 30분 분량이면 충분합니다*
- [ ] 두 번째 게임잼 참가 — **이번엔 음악까지 직접**
- [ ] 작업 과정 글 **1편** 쓰기 *· 결과물보다 과정 기록이 포트폴리오가 됩니다*
- [ ] 1년치 결과물을 **한 페이지로** 정리 — 첫 스프라이트와 마지막 스프라이트를 나란히

> **완료 기준** — itch.io에 아트·음악 전부 본인 크레딧인 게임 1개, 그리고 그 과정을 설명한 글 1편.

## 주기별로 할 것

단계와 무관하게 12개월 내내 유지하는 리듬입니다.

| 주기 | 할 것 | 왜 |
| --- | --- | --- |
| **매일** | 30분, 같은 시간 | 실력은 총 시간이 아니라 반복한 날짜 수를 따라갑니다 |
| **주 1회** | 완성작 1개 — 스프라이트 1장 또는 8마디 루프 1개 | 미완성은 실력이 되지 않습니다 |
| **월 1회** | 이번 달 결과물을 한 장에 모아 보기 | 매일 보면 안 느는 것 같지만 한 달 단위로는 확실히 보입니다 |
| **3개월마다** | 게임잼 참가 | 마감이 완벽주의를 없애고, 실제로 돌아가는 결과물이 남습니다 |

## 실패하는 세 가지 방식

거의 모든 중도 포기가 이 셋 중 하나입니다.

**01 · 강의만 보고 안 만든다**
튜토리얼은 이해가 되니까 늘고 있다는 착각을 줍니다. 강의 1개를 봤으면 반드시 결과물 1개를 만드세요. 안 만들었으면 그 강의는 본 게 아닙니다.

**02 · 처음부터 잘하려 한다**
첫 100장은 못 그리는 게 정상입니다. 목표는 잘 그리는 게 아니라 그 100장을 빨리 소진하는 것입니다. 음악도 첫 50곡은 버리는 곡입니다.

**03 · 둘을 동시에 한다**
하루 30분을 그림 15분 + 음악 15분으로 쪼개면 둘 다 안 늡니다. 이 로드맵이 그림 4개월, 음악 4개월로 나눠 놓은 이유입니다.
